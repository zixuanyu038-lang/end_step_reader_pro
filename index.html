如何转交给 Codex

1. 在回合索引选择操作，下载 codex-handoff.json。
2. 在 Codex 对话中附上该文件，或告诉 Codex 文件的完整本地路径。
3. 点击“复制交接提示词”，粘贴到同一对话并发送。
4. 将返回的 branch.json 导入右侧面板。

复盘、步骤和日志都使用完整英文牌名，例如 Tamiyo, Inquisitive Student、Flame of Anor、Disruptor Flute；不使用译名或昵称。

目标是双方完整后续。未知牌和牌序由 Codex 合理假设，清单列出依据，受影响步骤标注假设编号。当前本地执行器只支持有限片段，不能注入假设牌或执行未知抽牌。文件包含原回放及手牌信息；此页面不会自动发送给 Codex。

阅读说明

导入 Endstep 的 .esreplay 文件，即可按局、回合、阶段阅读中文战报。支持拖入文件，也支持未压缩的 JSONL。切换「原始 JSONL」可直接查看、筛选或保存完整原始记录。

事件与操作
战报只根据游戏事件生成。玩家点击、自动支付和取消操作不作为已成功执行的事实。
施放与结算
施放不代表结算；离开堆叠不直接代表被反击。触发异能与来源咒语分别记录。
隐藏信息
只呈现录制视角能看到的信息。对手的未知手牌不会被补全；牌库移入手牌不一律叫作抓牌。
语言与兼容
牌名使用文件中的英文名；常见操作翻译为中文。无法可靠翻译的效应保留原文，未知事件也会保留。当前验证版本为 Endstep Replay v1。
快捷键
← → 切换回合，/ 搜索。导出的 HTML 可离线打开，包含整场战报及已记录的手牌信息。

术语参考 万智牌官方规则 ↗（121.1、113.7a、701.6）。本工具整理记录，不模拟规则或评判最优操作。
